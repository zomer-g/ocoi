## English

### Name (≤75 chars)
```
OCOI — Conflict-of-Interest Map
```

### Summary (≤132 chars)
```
Highlights Israeli officials, companies, and associations on any web page and shows their OCOI relationship map in one click.
```

### Category
Productivity

### Detailed description (≤16,000 chars)

```
A free extension that bridges the pages you read and the public dataset
behind ocoi.org.il — Israel's transparency platform for conflict-of-interest
declarations of public officials.

What it does:
• Scans the current page after you click the toolbar icon.
• Underlines names of public officials, companies, and associations that
  have a record in OCOI.
• Clicking a marked name opens a floating window with a first-degree
  relationship map — who is connected to whom, holding companies,
  declared conflicts of interest.
• Or select any text on the page and right-click → "Look up on OCOI"
  for an ad-hoc lookup without scanning the whole page.

Useful for:
• Journalists — quickly check the business connections of a source or
  interviewee.
• Citizens — verify potential conflicts of interest for an official
  named in an article.
• Professionals — jump from a name in a long document straight to the
  full record on OCOI.

Privacy & transparency:
• The extension does not run automatically. A scan happens only after
  you click the toolbar icon, or after you right-click selected text.
• The text you choose to scan is sent only to www.ocoi.org.il, solely
  to perform the lookup. No server-side logging beyond standard
  webserver logs.
• No data is sent to third parties. No ads, no tracking.
• We do not collect names, cookies, or browsing history.

Limitations:
• OCOI's content is built from filed conflict-of-interest declarations
  and the official Israeli company/association registries. It is not
  guaranteed complete or fully up to date — the absence of an entity
  is not evidence that no information about it exists.
• Name detection is based on string matching. Coincidentally identical
  names can produce a marker for the wrong entity. The floating window
  always shows the entity type and links to the full OCOI record so
  you can verify.

Source code is published in the public OCOI repository.
Questions / feedback: guy@z-g.co.il
```
